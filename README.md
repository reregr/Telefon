# Telefoncu Simulator Full Edition

Android / çevrimdışı / tek oyunculu telefoncu işletme simülasyonu.

## APK oluşturma
1. ZIP'i bilgisayara/telefona indirip çıkar.
2. Dosyaları GitHub deposunun kök dizinine yükle (app, .github, gradle dosyaları dahil).
3. GitHub > Actions > Telefoncu Simulator APK > Run workflow.
4. İşlem tamamlanınca Artifact bölümünden `TelefoncuSimulator-Full-APK` dosyasını indir.
5. İndirilen ZIP'i açıp `app-debug.apk` dosyasını Android cihaza kur.

## Kapsam
- 50 telefon modeli, depolama seçenekleri ve kondisyonlu ikinci el cihazlar
- Müşteri oluşturma, müşteri talepleri, pazarlık ve ekspertiz
- Ekran/batarya/kamera/şarj soketi/hoparlör/arka kapak/anakart tamir akışı
- Parça kalitesi, stok, mini tamir adımları, test ve teslim
- Toptancı, kampanya, döviz kuru ve piyasa fiyatları
- Oyun içi ilan sitesi, müşteri teklifleri ve satış
- Aksesuar envanteri, kasa, kira, günlük giderler, itibar ve dükkan yükseltmeleri
- Otomatik yerel kayıt (localStorage), çevrimdışı oynanış

Not: Oyun gerçek Sahibinden, gerçek ödeme, gerçek IMEI sorgusu veya canlı döviz servisine bağlanmaz. İlan ve piyasa verileri oyun içi simülasyondur.
